# Event Registration System

A professional Event Registration System built using Django.  
This project allows users to view events, register for events, manage registrations, and provides an admin panel for event management.

---

##  Features

- User-friendly frontend interface
- Professional pastel-themed UI
- Event listing page
- Event detail page
- Event registration form
- View registrations
- Cancel registrations
- Django admin panel
- Backend database integration
- Responsive design

---

##  Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite
- Bootstrap
